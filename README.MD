# Canensonic
From the roman personification of song, Canens, Canensonic is an OpenSubsonic-compatible music server, 
with some social features added on top. 

It is a from-scratch rewrite of [SocialSonic](https://github.com/TarjeiSvendsen/SocialSonic), 
as I have learned a lot since then, and want to incorporate some of my learnings into a project.
